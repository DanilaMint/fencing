# Fencing

## Запуск

У программы три режима:

- `fight` — бой: поединок двух бойцов в окне;
- `train-strategist` — обучение стратегов: эволюция клуба бойцов;
- `train-eugenics` — обучение перцептронов: генетический алгоритм;
- `benchmark` — сравнение двух поколений бойцов.

```sh
cargo run -- fight                    # игра с окном
cargo run -- fight --no-gui           # без окна: только симуляция, без отображения
cargo run -- --help                   # список режимов
cargo run -- fight --help             # опции режима боя
```

### Мозги бойцов

У каждого бойца свой мозг, он задаётся флагом `--red` или `--blue`.
Значение — либо имя встроенного мозга, либо путь к файлу с обученным мозгом:

```sh
cargo run -- fight --red=player --blue=firsts/epoch_08/firsts_00.json
cargo run -- fight --red=firsts/epoch_08/firsts_00.json --blue=firsts/epoch_08/firsts_01.json
```

- `player` — боец под управлением игрока (клавиатура и мышь);
- `doll` — заглушка: боец ничего не делает (значение по умолчанию);
- `perceptron` — боец под управлением нейросети со случайными весами;
- путь к `.json` — обученный мозг: боец играет по таблице реакций стратега
  или по сети, в зависимости от того, чем сохранён файл.

Файл сам объявляет, какой моделью мозга он создан, так что один и тот же путь
подходит и стратегу, и сети. Если в файле указана незнакомая модель мозга,
игра не запустится и скажет об этом в ошибке. Без окна (`--no-gui`) управлять
бойцом нечем, поэтому `player` там заменяется заглушкой.

## Правила

### Тело бойца

Боец состоит из туловища, головы, руки с мечом и левой руки. 

Туловище — эллипс: шире, чем глубже (плечи шире, чем корпус спереди назад). Эллипс поворачивается вместе с бойцом, и столкновения считаются по его форме.

### Действия

Он может двигаться в 8 сторон относительно своей оси, поворачиватся в обе стороны. Оба действия происходят с постепенным ускорением до максимальной скорости.

Также может наносить удары мечом: 
- колющий - меч идет прямо с ускорением, 
- рубящий - меч идет по окружности, уходя вперед и набирая скорость. 

после удара меч возвращается к стойке.

### Состояние бойца

У бойца есть показатель состояния с двумя шкалами: **Выносливость**, **Энергия**
- Действия бойца расходуют энергию, удары расходуют сильнее всего. 
- Энергия не может быть больше выносливости, если выносливость опустилась ниже уровня энергии, то энергия снижается до уровня выносливости.
- Когда энергия доходит до нуля, начинает понижаться выносливость. 
- Когда выносливость доходит до нуля - нокаут. 
- Пока боец ничего не делает, его энергия повышается
- Когда энергия доходит до значения выносливости, то оба показателя начинают расти, но в 2 раза медленнее.

Эффект шока - состояние, когда мозг бойца временно не может отправлять комангды телу.

### Столкновение с мечом

- **меч оппонента** - если он наносит удар, то оба удара считаются отраженными и уходят в исходное положение. Если меч оппонента в неактивном состоянии - они не сталкиваютя
- **туловище** - снижает выносливость, количество зависит от силы удара
- **голова** - как по туловищу, но накладывает эффект шока
- **левая рука** - как по туловищу, но урон в несколько раз меньше

### Мозг бойца
Является функцией f(ситуация на ринге) -> реакция

Есть четыре вида мозгов:
- **игрок** - читает клавиатуру и мышь
- **заглушка** - ничего не делает
- **стратег** - учится по правилу "стимул -> реакция"
- **перцептрон** - играет нейросетью

#### Стратег

У стратега есть таблица из N записей "стимул -> реакция". Изначально все записи пустые.

**Стимул** - это снимок обстановки: расстояние до центра ринга, расстояние до противника и углы (до противника, от противника, до центра). Все признаки нормированы, поэтому сравнимы между собой. По формуле похожести боец получает число похожести между стимулом и каждой записью (0 - полное совпадение). Если похожесть меньше порога (константа с небольшим случайным шумом), боец берёт эту реакцию. Если похожих записей нет - он занимает позицию с самым низким рейтингом и записывает туда новую случайную реакцию, получая авансовый рейтинг.

**Реакция** - это таблица из 8 этапов. В каждом этапе боец может:
- идти в одном из восьми направлений в течение от 0 до 1/2 секунды,
- параллельно поворачивать влево или вправо,
- в первый тик этапа - ударить колющим или рубящим ударом.

Этап заканчивается, когда отработали все его команды. Если меч ещё занят предыдущим ударом, удар ждёт готовности и наносится позже - навигация при этом продолжается. Все 8 этапов подряд - одна реакция.

**Рейтинг** показывает, насколько удачной оказалась реакция. Он считается по событиям боя за время реакции: нанесённый удар и отбитый удар противника добавляют очки, полученный удар, шок и потраченная впустую энергия - отнимают. Сюда же идёт изменение положения на ринге: отход от центра проигрышен, отталкивание противника от центра - выигрышно. Когда рейтинг падает ниже нуля, запись стирается.

Удар в голову прерывает выполнение реакции. Когда реакция закончилась, боец снова анализирует ситуацию и выбирает следующую.

Таблицу можно сохранить в файл и загрузить обратно, чтобы обучение не терялось между боями.

#### Перцептрон

Мозг на нейросети. Каждый тик сеть смотрит на обстановку и выдаёт команду бойцу.

**Вход** - двенадцать чисел из ситуации на ринге, все нормированы к своим диапазонам:
- пять геометрических: расстояние до центра ринга, расстояние до противника,
  угол до противника, угол от противника, угол до центра;
- три динамических: своя угловая скорость, угловая скорость противника,
  скорость сближения;
- четыре своих: готов ли меч к удару, своя энергия, своя выносливость,
  расстояние противника от центра ринга.

Последние четыре даны не просто так: без готовности меча сеть не может поймать
момент для удара, без своей энергии - сэкономить силы, а без положения
противника относительно центра - вытолкнуть его с ринга.

**Сеть** - один скрытый слой (16 нейронов, `tanh`) и четырнадцать выходов в трёх группах:
восемь отвечают за направление движения, три - за поворот, три - за тип удара.
Внутри каждой группы вероятности нормируются отдельно, и действие выбирается
из них случайно - так поведение стохастично.

**Сохранение** - тот же формат, что у стратега: файл сам объявляет модель мозга,
поэтому обученные сети можно копить рядом со стратегами.

```sh
cargo run -- save-perceptron --out perceptron.json --seed 7
cargo run -- fight --red=perceptron.json --blue=perceptron.json
```

Опции режима сохранения: `--out` (файл), `--seed` (зерно: одинаковое зерно -
одинаковый мозг), `--hidden` (ширина скрытого слоя), `--name` (имя бойца).

Обучение сети делает генетический алгоритм (см. «Генетическое обучение клуба»):
веса сети - это геном бойца, а отбор идёт по очкам, набранным в боях.

#### Обучение клуба

Клуб бойцов тренируется отдельно от игры:

```sh
cargo run --release -- train-strategist                       # 16 бойцов, 100000 спарингов на пару, 8 эпох
cargo run --release -- train-strategist --fighters 4 --sparring 20 --epochs 3
```

Опции режима обучения: `--club` (имя клуба), `--fighters` (число бойцов),
`--epochs` (число эпох), `--sparring` (спарингов на пару за эпоху), `--seed` (зерно),
`--out` (каталог с бэкапами и отчётом).

За эпоху каждая пара встречается заданное число раз, причём спаринги разных пар
перемешаны: бойцы не привыкают к одному противнику. Спарсинги идут параллельно,
но в пределах одной волны боец участвует не более чем в одном бою - иначе
состояния двух реакций перемешались бы в общем стратеге.

После каждой эпохи сохраняются:

```
firsts/
  epoch_01/
    club.json        - общее состояние клуба
    firsts_00.json   - таблица бойца: в файле указано, что это стратег
    ...
  epoch_02/ ...
  report.md          - отчёт обучения
```

Обучение можно прервать и продолжить: при следующем запуске клуб загружается
из последнего бэкапа. Файлы бойцов самодостаточны - по метке `model` понятно,
какой моделью мозга они созданы, так что обученные стратеги можно копить рядом
с мозгами других моделей.

#### Генетическое обучение клуба

Перцептрон обучается эволюционно: геном бойца - это веса его сети.

```sh
cargo run --release -- train-eugenics                    # клуб club_eugenics, 8 элит, 20 поколений
cargo run --release -- train-eugenics --generations 50 --mutation-rate 0.1
```

Как устроено поколение:

- клуб состоит из **элиты** - восьми сильнейших бойцов прошлого поколения;
- элита оставляет **56 наследников**: их геномы скрещиваются (каждый ген берётся
  от одного из двух родителей) и мутируют (случайный шум с ограничением по
  пределам слоя);
- в поколении оказывается **64 бойца**: восемь элит и пятьдесят шесть наследников;
- все они дерутся между собой: каждый с каждым по одному разу, это 2016 боёв;
- очки у всех начинаются с 1000 и меняются по расценке:

| Исход боя | Победителю | Проигравшему |
|---|---|---|
| Ничья | −1 | −1 |
| Выход за ринг | +1 | −1 |
| Выдохся от энергии | +2 | −2 |
| Выдохся от удара | +4 | −4 |

Расценку можно сменить флагом `--scoring=epic`: там добивание от удара стоит
+8 очков, измор всего +1, ничья штрафуется тройкой, а каждый нанесённый удар
даёт ещё очко. При такой расценке отбор ведёт к бою, а не к измору.

- в следующее поколение проходят восемь бойцов с наивысшими результатами.

Очки обнуляются в каждом поколении, поэтому ранжирование отражает только
результаты текущего поколения. Нокаут от удара - самый дорогой исход, значит
отбор поощряет бойцов, которые не просто держатся на ринге, а добивают.

Опции режима: `--club` (имя клуба), `--elite` (размер элиты), `--offspring`
(наследников за поколение), `--generations` (число поколений), `--repeat` (боёв
на пару), `--hidden` (ширина скрытого слоя), `--mutation-rate`, `--mutation-scale`,
`--crossover-rate`, `--tournament` (размер турнира при выборе родителей),
`--scoring` (`classic` или `epic`), `--seed`, `--out` (каталог с бэкапами и
отчётом).

После каждого поколения сохраняются:

```
club_eugenics/
  epoch_01/
    club.json              - состояние клуба: элита, геномы, сводки поколений
    club_eugenics_00.json  - мозг элиты: в файле указано, что это перцептрон
    ...
  epoch_02/ ...
  report.md                - отчёт обучения
```

Обучение можно прервать и продолжить: при следующем запуске клуб загружается
из последнего бэкапа. Мозг элиты годится для обычного боя:

```sh
cargo run -- fight --red=club_eugenics/epoch_01/club_eugenics_00.json --blue=club_eugenics/epoch_01/club_eugenics_01.json
```

В отчёте есть колонка «Сила» - доля побед элиты поколения над замороженной
элитой первого поколения. Половина означает, что поколение не сильнее первого.

#### Сравнение поколений

Два каталога с мозгами можно сравнить напрямую - кто из них сильнее:

```sh
cargo run --release -- benchmark --first=club_eugenics/epoch_10 --second=club_eugenics/epoch_40
```

Режим печатает число боёв, победы, ничьи и долю побед первой группы. Это
главный прибор: если новое поколение побеждает старое заметно чаще, эволюция
идёт; если разница в пределах шума, алгоритм топчется на месте.

### Раунд
Ринг имеет круглую форму. 
Если боец вышел за пределы ринга - считается проигравшим. 
Раунд ограничен по времени - 120 секунд. если время вышло, то объявляется ничья.
Если боец был отправлен в нокаут от истощения - он считается проигравшим.
Нокаут от удара - тоже поражение, но в отчёте он считается отдельным исходом.
